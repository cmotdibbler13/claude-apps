# claude-apps
claude produced apps

## Apps

- [autocue-studio](autocue-studio/) - Windows teleprompter and voice recorder for narrating videos, line by line
- [claude-usage-widget](claude-usage-widget/) - Windows taskbar strip showing Claude 5-hour and 7-day usage next to the clock
- [six-minutes-studio](six-minutes-studio/) - Claude desktop app page that runs the Six Minutes On... film pipeline: shots, takes, jobs and review
- [stem-remixer](stem-remixer/) - Windows app that splits a song into vocals, drums, bass and other instruments and lets you remix them
- [t2-fan-control](t2-fan-control/) - Fan control and temperature monitoring for T2 Intel Macs running Windows (Boot Camp)
- [youtube-downloader](youtube-downloader/) - Windows app to save YouTube videos as MP4 (or MP3) to watch offline

Unofficial personal projects. Not made, endorsed or supported by Anthropic. Released under the [MIT licence](LICENSE).
